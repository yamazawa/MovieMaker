[SP1]MovieMaker_実装方針

前提 : 同フォルダのMovieMaker_仕様書.md(SP1版)を前提とする。

# 全体構成

- .NET 9 / WPF (`net9.0-windows10.0.19041.0`)、CommunityToolkit.Mvvm
- DIコンテナは使わず、App.xaml.csのOnStartupで手動組み立てる(CardAdjust同様)
- ドラッグ移動・8方向リサイズは、CardAdjustのDragMoveBehavior/ResizeHandleBehaviorを移植する

# タスク1 - プロジェクト基盤構築と画面骨格

[完了イメージ]
- csproj・フォルダ構成(Models/ViewModels/Views/Services/Behaviors/Converters/Styles/Resources)が揃う
- MainWindowが起動し、作成モード/再生モードの空の画面が切り替わる

# タスク2 - 文字オブジェクトの配置・ドラッグ・リサイズ

[完了イメージ]
- 「文字を追加」ボタンでキャンバス中央に文字オブジェクトが追加される
- ドラッグで移動、8方向ハンドルでリサイズできる
- クリックで選択状態になる

# タスク3 - 画像オブジェクト(クリップボード貼付)の配置・ドラッグ・リサイズ

[完了イメージ]
- 「画像を追加」ボタンで、クリップボードの画像がキャンバス中央に追加される
- ドラッグ・リサイズ・選択は文字オブジェクトと同様に動作する

# タスク4 - パレットでのプロパティ編集

[完了イメージ]
- 選択中オブジェクトがある場合、パレットに編集項目が表示される
- 文字オブジェクトは文字内容・文字サイズを編集できる
- 表示開始・終了時刻を0.1秒単位で編集できる

# タスク5 - タイムライン(スライドバー兼タイミングチャート)

[完了イメージ]
- 下部にスライドバーが表示され、ドラッグで現在時刻が移動する
- 各オブジェクトの表示区間が横棒で表示される
- 現在時刻に応じて、キャンバスの表示オブジェクトが切り替わる

# タスク6 - プロジェクトの自動保存・起動時復元

[完了イメージ]
- オブジェクトの追加・編集・削除のたびに自動保存される
- 再起動時に保存済みの内容が復元される

# タスク7 - 再生モード

[完了イメージ]
- モード切替ボタンで再生モードに切り替わる
- 再生モードではキャンバスのみが表示され、時刻0からループ再生される
- 作成モードに戻ると、再生は停止し編集操作に戻る
